# Java Engineering: A Comprehensive Guide for Professionals

---

## Course Overview

This curriculum provides a rigorous, end-to-end exploration of the Java programming language and its ecosystem. It is designed for aspiring software engineers, computer science students, and working professionals who seek to build production-grade Java applications grounded in sound engineering principles.

Each module progresses from foundational theory to practical implementation, culminating in a capstone project that integrates all concepts into a cohesive, tested application.

---

## Prerequisites

- Familiarity with basic computer science concepts (variables, logic, algorithms).
- A working installation of JDK 17 or later.
- An IDE such as IntelliJ IDEA, Eclipse, or VS Code with Java extensions.
- Git installed and configured on your system.

## How to Use This Guide

1. **Sequential Study**: Modules are ordered by dependency. Complete them in sequence for the best learning experience.
2. **Hands-On Practice**: Every module concludes with a "Code in Practice" section. Type and run every example; do not copy-paste.
3. **Diagram Comprehension**: Study the Mermaid diagrams carefully. They represent the mental models that distinguish junior developers from senior engineers.
4. **Capstone Preparation**: Modules 01 through 12 each contribute a skill that is directly required in the Module 13 capstone project.

## Conventions Used

- `monospace` denotes code identifiers, filenames, and terminal commands.
- **Bold** text marks critical definitions or warnings.
- All code examples are written for **JDK 17+** and follow standard Java naming conventions.
- SQL examples target MySQL/MariaDB syntax but are easily adaptable to PostgreSQL.
